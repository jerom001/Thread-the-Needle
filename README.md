# Thread-the-Needle

Thread-the-Needle is a fast-paced 2D reaction game built in Unity for **Jame Gam #58**.

Created around the jam theme **Direction** and the required special object **Needle**, the game challenges players to quickly rotate a center needle and match its direction with incoming arrow buttons before they reach the center.

The mechanic focuses on timing, accuracy, and fast reactions.

## Gameplay

A needle remains fixed at the center of the screen.

Arrow buttons with random directions spawn from the left side and move toward the center.

Players rotate the needle with the mouse and must align the needle’s point with the matching arrow before the button reaches it.

### Scoring

- Correct match = **+1 point**
- Wrong direction = **lose 1 life**

### Lives

Players start with **3 lives**

The run ends when all lives are lost.

### Controls

- **Mouse movement** — rotate the needle
- **ESC** — pause

## Game Jam

Created for **Jame Gam #58**

### Theme
**Direction**

### Special Object
**Needle** *(any type)*

### Jam Interpretation

The game was designed around interpreting both requirements directly:

- **Direction** → matching arrow directions in real time
- **Needle** → the central rotating needle as the core gameplay mechanic

Combining both created a fast reaction-based challenge where players constantly read direction and rotate the needle accurately under pressure.
